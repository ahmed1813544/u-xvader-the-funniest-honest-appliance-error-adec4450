`main.py` (Python 3.13 stdlib only) writes one line — the funniest honest error message an appliance could show — to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
